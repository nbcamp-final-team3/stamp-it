## 🛠️ 기술 스택 & 개발 환경

- **언어**: Swift
- **UI 프레임워크**: UIKit (Code-Base)
- **아키텍처**: MVVM + Clean Architecture
- **데이터베이스**: Firebase Firestore
- **인증**: Firebase Auth (구글, 애플 소셜 로그인)

### 📚 외부 라이브러리

- 🧩 **SnapKit** – UI 오토레이아웃 코드 작성
- 🧠 **RxSwift / RxCocoa** – 반응형 프로그래밍
- ✨ **Then** – 인스턴스 초기화 간소화
- 🎞️ **Lottie** – 애니메이션 효과
- 🔥 **Firebase-SDK** – 데이터베이스 및 인증
- 🔐 **GoogleSignIn** – 구글 소셜 로그인

## ✨ 주요 기능

### 🏠 **온보딩 + 로그인 기능**
- 📊 **온보딩**: 앱에 대한 소개와 목표를 간단하게 제공 (앱 최초 접속 시 제공)
- 📊 **소셜 로그인(구글, 애플)**: 애플, 구글 계정으로 편리하게 서비스 이용 가능
- 📊 **자동 로그인**: 처음 로그인 시 인증 만료 전까지 자동로그인

### 🏠 **홈 화면**
- 📊 **그룹 랭킹**: 이번 달 스티커 개수로 순위 표시
- 🎯 **나의 미션**: 할당받은 미션 목록 확인과 진행 완료 체크
- 👥 **멤버 미션**: 다른 구성원에게 부여한 미션 현황
- ✅ **미션 완료**: 3초 취소 가능한 완료 처리

### 🎯 **미션 시스템**
- 📝 **앱 제공 미션**: 4가지 카테고리 (집안일, 가족소통, 건강운동, 독서학습)
- 🔍 **미션 검색**: 키워드 및 카테고리별 필터링
- ⏰ **미션 기한**: 미션 기한이 지나면 자동 만료 처리
- 🎁 **스티커 보상**: 미션 완료 시 스티커 획득 (마이페이지 확인 가능)

### 🏆 마이페이지 + 스티커판 
- 🍇 **월별 스티커판**: 포도 모양 스티커 수집'
- 📈 **진행률 표시**: 개인 스티커 현황(스티커 총 개수, 이전 스티커판 확인)

### 👤 마이페이지 + 프로필 
- 🖼️ **프로필 관리**: 닉네임, 프로필 이미지 변경
- 🔐 **계정 관리**: 로그아웃, 서비스탈퇴

### 👤 마이페이지 + 프로필(그룹관리) 
- 🔗 **초대 시스템**: 링크 복사로 간편한 그룹 초대 및 가입 가능
- 👑 **그룹 리더**: 그룹명 변경, 멤버 관리 권한
- 🚪 **그룹 탈퇴**: 기존 그룹 탈퇴 후 1인 그룹 자동 생성

│   └── 📂 UseCases        # 유스케이스
├── 📂 Presentation        # UI 계층
│   ├── 📂 Home            # 홈 화면
│   ├── 📂 Group           # 그룹 관리
│   ├── 📂 Mission         # 미션 관리

## 🚀 주요 구현 사항

### ✅ **MVP 완료 기능**

#### 🔐 **인증 시스템**
- 구글/애플 소셜 로그인
- 자동 로그인 및 세션 관리
- 온보딩 화면 (최초 접속 시)

#### 👥 **그룹 시스템**
- 회원가입 시 1인 그룹 자동 생성
- 초대 코드를 통한 그룹 가입
- 그룹 탈퇴 및 멤버 관리

#### 🎯 **미션 관리**
- 4개 카테고리별 미션 제공
- 미션 검색 및 필터링
- 미션 할당 및 기한 설정
- 미션 완료 처리 (3초 취소 가능)

#### 🏆 **스티커 & 랭킹**
- 미션 완료 시 스티커 자동 부여
- 월별 개인 스티커판
- 그룹 내 랭킹 시스템

#### 👤 **프로필 관리**
- 닉네임 변경 (월 1회 제한)
- 프로필 이미지 설정
- 계정 관리 기능
