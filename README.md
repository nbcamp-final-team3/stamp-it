# 📱 스탬프잇 (Stamp-It)

> 🏠 **가족, 룸메이트, 공동체가 함께하는 미션 완료 앱**

## ✨ 주요 기능

### 🔁 **온보딩 + 로그인 기능**
- 📊 **온보딩**: 앱에 대한 소개와 목표를 간단하게 제공 (앱 최초 접속 시 제공)
- 🔑 **소셜 로그인(구글, 애플)**: 애플, 구글 계정으로 편리하게 서비스 이용 가능
- 🗝️ **자동 로그인**: 처음 로그인 시 인증 만료 전까지 자동로그인

### 🏠 **홈 화면**
- 📊 **그룹 랭킹**: 이번 달 스탬프 개수로 그룹내 멤버 순위 표시
- 🎯 **나의 미션**: 할당받은 미션 목록 확인과 진행 완료 체크
- 👥 **멤버 미션**: 다른 구성원에게 부여한 미션 현황(멤버별, 상태별 필터링 기능)
- ✅ **미션 완료**: 3초 취소 가능한 완료 처리(토스트), 준 미션-완료 미션도 모두 취소 가능

### 🎯 **미션 시스템**
- 📝 **앱 제공 미션**: 5가지 카테고리 (즐겨찾기, 집안일, 가족소통, 건강운동, 독서학습)
- 🗒️ **커스텀 미션**: 직접 부여하고 싶은 미션을 작성해서 팀원에게 할당
- 🔍 **미션 검색**: 키워드 및 카테고리별 필터링
- ⭐ **미션 즐겨찾기**: 자주 사용하는 미션을 즐겨찾기로 관리(상단고정, 카테고리)
- 🎯 **추천 미션**: 사용자 행동 패턴 기반 맞춤 미션 추천
- ⏰ **미션 기한**: 미션 기한이 지나면 자동 만료 처리
- 🎁 **스탬프 보상**: 미션 완료 시 스탬프 획득 (마이페이지 확인 가능)

### 🏆 마이페이지 + 스탬프판 
- 🍇 **월별 스탬프판**: 스탬프 수집
- 📈 **진행률 표시**: 개인 스탬프 현황(스탬프 총 개수, 완성한 스탬프판 개수)
- 📜 **여러개의 스템프판 확인**: 총 4개의 스탬프판을 페이징으로 확인 가능
- 🌟 **스탬프 상세 정보 확인**: 스탬프 획득일, 미션 부여자, 미션내용 등을 확인 능

### 👤 마이페이지 + 프로필 
- 🖼️ **프로필 관리**: 닉네임, 프로필 이미지 변경
- 🔐 **계정 관리**: 로그아웃, 서비스탈퇴

### 👤 마이페이지 + 프로필(그룹관리) 
- 🔗 **초대 시스템**: 코드 복사로 간편한 그룹 초대 및 가입 가능
- 👑 **그룹 리더**: 그룹명 변경, 멤버 관리 권한(멤버 내보내기, 리더 위임)
- 🚪 **그룹 탈퇴**: 기존 그룹 탈퇴 후 1인 그룹 자동 생성

## 🏁 주요 개발 성과

### 1. **커스텀 미션 구현, 즐겨찾기, 추천 미션 시스템 구현**
- **커스텀 미션추가**: 사용자가 직접 커스텀한 미션을 부여할 수 있어 유연성 증가
- **사용자 행동 기반 점수 시스템**: 미션 탭(0.1점), 전달하기(0.4점)로 개인화된 추천 제공
- **즐겨찾기**: 즐겨찾기 지정 시 해당 미션이 상단에 고정 되어 사용자 경험 증가

### 2. **버전 호환성 관리 시스템**
- **강제 업데이트 메커니즘**: Firebase 기반 실시간 버전 체크 및 자동 앱스토어 이동
- **호환성 문제 해결**: 새로운 enum 케이스 추가로 인한 크래시 방지
- **유연한 메시지 관리**: 서버 설정만으로 업데이트 안내 메시지 실시간 변경

### 3. **사용자 경험 개선**
- **키보드 UI 최적화**: 다양한 디바이스에서 입력 시 UI 가림 현상 해결
- **미션 완료 취소 로직**: 홈화면에서 즉시 API 호출 및 토스트 피드백 제공
- **필터링 기능 강화**: 멤버별, 상태별 미션 현황 필터링으로 관리 편의성 향상
